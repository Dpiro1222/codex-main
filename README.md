# AI情報収集 & X投稿案生成ツール

AIビジネス系の最新情報を自動収集し、X（旧Twitter）の投稿案を生成してNotionに保存するPython CLIツールです。

## 機能概要

| ステップ | 処理内容 | 使用API |
|---|---|---|
| STEP 1 | 過去24時間のAIビジネスニュースを5件収集（引用元に無いURLは除外、Notion保存済みのネタはスキップ） | Perplexity (`sonar-pro`) |
| STEP 2 | 3軸（バズ・社長の自分ごと度・発信者との必然性）で採点し、平均7点以上のみ通過 | Claude (`claude-sonnet-4-6`) |
| STEP 3 | `best_posts.txt` のお手本を参考に3パターンの投稿案を生成（140文字超過は1回だけ自動短縮） | Claude (`claude-sonnet-4-6`) |
| STEP 4 | 結果をNotionデータベースに保存 | Notion API |

## セットアップ

### 1. リポジトリをクローン

```bash
git clone <repo-url>
cd codex-main
```

### 2. Python環境を準備

Python 3.11以上を推奨します。

```bash
pip install -r requirements.txt
```

### 3. 環境変数を設定

`.env.example` をコピーして `.env` を作成し、各APIキーを入力します。

```bash
cp .env.example .env
```

`.env` の内容：

```env
ANTHROPIC_API_KEY=sk-ant-...        # Anthropic コンソールで取得
PERPLEXITY_API_KEY=pplx-...         # Perplexity コンソールで取得
NOTION_API_KEY=secret_...           # Notion インテグレーションのシークレット
NOTION_DATABASE_ID=xxxxxxxx...      # 保存先NotionデータベースのID
```

#### APIキーの取得方法

- **Anthropic**: https://console.anthropic.com/
- **Perplexity**: https://www.perplexity.ai/settings/api
- **Notion**: https://www.notion.so/my-integrations → 新しいインテグレーションを作成

#### Notion Database IDの確認方法

Notionでデータベースページを開き、URLの以下の部分をコピーします。

```
https://www.notion.so/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx?v=...
                       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                       これがDATABASE_ID
```

### 4. Notionデータベースの準備

以下のプロパティを**日本語名・指定の型で**作成してください。

| プロパティ名 | 型 |
|---|---|
| タイトル | タイトル（デフォルト） |
| ネタ元URL | URL |
| バズスコア | 数値 |
| 投稿案A | テキスト |
| 投稿案B | テキスト |
| 投稿案C | テキスト |
| ステータス | セレクト（選択肢に「確認待ち」を追加） |
| 収集日 | 日付 |

作成後、データベースの「共有」からインテグレーションを招待してください。

### 5. お手本の投稿を登録（推奨）

`best_posts.txt` に、自分のXで反応が良かった過去投稿を3〜5本貼ります（`---` の行で区切る）。口調と構成を真似た投稿案が出るようになります。空のままでも動きます。

## 実行方法

```bash
python main.py
```

これだけでSTEP 1〜4が順に実行されます。

### 毎朝の自動実行（GitHub Actions）

`.github/workflows/daily.yml` が毎朝7:00（日本時間）に実行します。リポジトリの Settings → Secrets and variables → Actions に、`.env` と同じ4つのキーを登録してください。Actions タブの「Run workflow」から手動実行もできます。

## 投稿パターンについて

| パターン | 種類 | 概要 |
|---|---|---|
| A | ノウハウ暴露型 | 具体的なtipsや方法論を明かす |
| B | 業界批評型 | 業界の問題点や非常識を指摘する |
| C | 数字報告型 | ネタ内の数字を主役にし、中小企業にとっての意味を言い切る |

数字はネタに書かれているものだけを使います。自社の実績を入れたい箇所は `【自社数値】` と空欄で出るので、投稿前に自分で埋めてください。

## ファイル構成

```
codex-main/
├── main.py          # メインスクリプト（これを実行するだけ）
├── requirements.txt # Python依存パッケージ
├── best_posts.txt   # 投稿案のお手本（自分の伸びた過去投稿）
├── .github/workflows/daily.yml # 毎朝7:00 JSTの自動実行
├── .env             # 環境変数（要作成、Gitにコミット禁止）
├── .env.example     # 環境変数テンプレート
├── README.md        # このファイル
└── CLAUDE.md        # AI向けコードベース解説
```

---

## 注意事項

- `.env` は絶対にGitにコミットしないでください
- Notion側のプロパティ名は**日本語・完全一致**が必要です
- スコアリングのしきい値（7点）はSTEP 2の品質ゲートです
- API利用料が発生します（Perplexity・Anthropic・Notionそれぞれ）
